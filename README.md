# NYC Climate Data Analysis

## Project Overview
This project explores historical climate data for New York City using Python and MongoDB. It focuses on data cleaning, preprocessing, temperature trend analysis, meteorological anomalies, relationships between seasonal temperature and electricity demand, and comparisons of climate patterns between the 1990s and 2020s.

## Technologies Used
- **Python**
- **Pandas** – Data manipulation and analysis
- **MongoDB / PyMongo** – Data storage and database operations
- **Vega-Altair** – Data visualisation

## Dataset
### Climate Data
- **Data Source:** [Global Historical Climate Network (GHCN)](https://www.ncei.noaa.gov/cdo-web/datasets)
- **Weather Station:** Central Park, New York City
- **Station ID:** `GHCND:USW00094728`
- **Data:** Historical daily climate observations

### Electricity Demand Data
- **Data Source:** [New York Independent System Operator (NYISO) – Load Forecast Reports](https://www.nyiso.com/custom-reports?report=load_forecast)
- **Data:** Electricity demand and load forecast information for New York

## Key Activities
- Data cleaning and preprocessing
- Monthly and yearly temperature trend analysis
- Exploration of meteorological anomalies, including hurricane and flood events
- Analysis of the relationship between seasonal temperature and electricity demand
- Comparison of climate patterns between the 1990s and 2020s
- Interactive data visualisation using Vega-Altair
